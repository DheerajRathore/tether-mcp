# Tether

Tether is a macOS menu-bar app that lets AI clients such as Claude Desktop
read your Apple Notes through the Model Context Protocol (MCP).

- Runs entirely on your Mac. No hosted server.
- Read-only. Tether never modifies your notes.
- You control which services and tools are enabled.

> Status: early development. Notes first; Reminders, Calendar, Messages and Mail later.
